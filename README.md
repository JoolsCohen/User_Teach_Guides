# FLYONE Documentation Project: Dual-Audience Approach

Проект демонстрирует навык разделения единого массива информации на изолированные документы для разных целевых аудиторий: конечных пользователей (B2C) и технических специалистов (B2B/Dev).

---

## 🎯 Архитектура проекта

Проект разделен на два независимых руководства:

### 1. [Руководство пользователя (User Guide)](docs/user_guide.pdf)
* **Аудитория:** Пассажиры и клиенты сервиса бронирования.
* **Подход:** Task-oriented (ориентация на задачи пользователя).
* **Содержание:** 
  * Пошаговые сценарии (Поиск ➔ Выбор тарифа ➔ Оформление ➔ Оплата).
  * Тарифные сетки (Standard, Loyal, Advantage).
  * Раздел FAQ по типовым проблемам.
* **Визуализация:** Аннотированные скриншоты интерфейса.

### 2. [Техническая спецификация (API Reference)](docs/tech_api_guide.pdf)
* **Аудитория:** Backend/Frontend-разработчики, QA-инженеры, системные аналитики.
* **Подход:** System-oriented (структурированное описание логики и интерфейсов).
* **Содержание:** 
  * Спецификация REST API метода `GET /search-flights`.
  * Описание параметров запроса (Query Parameters) и JSON-ответов.
  * Клиентская логика (правила валидации ввода на Frontend).
  * Матрица обработки системных ошибок и HTTP-статусов.
